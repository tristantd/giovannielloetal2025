# Reproducibility Project - Giovanniello et al. (2025)
This repo reproduces and simulates the Stress X Contingency degradation group interaction from Henderson et al. (2025).

Reproduction of original data is in giovannielloetal2025/Original_data_reproduce.ipynb
Simulated data is in writeup/Giovannielloetal.2025_Sim.ipynb

You will need the following to run this:
  1. numpy
  2. pandas
  3. matplotlib.pyplot
  4. seaborn
  5. pingouin
  6. statsmodels.formula.api
  7. statsmodels.stats.power
